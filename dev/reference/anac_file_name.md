# Get the name of the file behind an ANAC download url

Get the name of the file behind an ANAC download url

## Usage

``` r
anac_file_name(file_url)
```

## Arguments

- file_url:

  Character vector of urls, possibly ending in `/@download/file`.

## Value

A character vector of file names (e.g. `"basica2020-04.zip"`).
