# Generate all months with `yyyymm` format for a given year

Generate all months with `yyyymm` format for a given year

## Usage

``` r
generate_all_months(date)
```

## Arguments

- date:

  Numeric. 4-digit date in the format `yyyy`. The function also takes
  multiple years.

## Value

Vector or strings.
