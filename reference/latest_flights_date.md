# Check the date of the latest flight data available

Check the date of the latest flight data available

## Usage

``` r
latest_flights_date()
```

## Value

A numeric date in the format `yyyymm`.

## See also

Other support function:
[`latest_airfares_date()`](https://ipeagit.github.io/flightsbr/reference/latest_airfares_date.md)
