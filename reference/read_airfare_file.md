# Read one airfare file and harmonize its column names

Read one airfare file and harmonize its column names

## Usage

``` r
read_airfare_file(path, showProgress = FALSE)
```

## Arguments

- path:

  String. Local file path.

- showProgress:

  Logical. Defaults to `TRUE` display progress.

## Value

A data.table with ANAC's current column names.
