## Core Principles

- **Plan first** — enter plan mode before non-trivial tasks; save plans to `quality_reports/plans/`
- **`R/` is authoritative** — `man/` (docs) and `NAMESPACE` are generated by roxygen2. Never hand-edit them; edit the roxygen blocks in `R/` and run `devtools::document()`
- **The release gate is `R CMD check --as-cran`** — 0 errors, 0 warnings, every remaining note justified in `cran-comments.md`. Run via [`/r-package-check`](https://github.com/ipeaGIT/flightsbr) before any release or merge that touches `R/`, `tests/`, or `DESCRIPTION`
- **[LEARN] tags** — when corrected, or when a non-obvious approach is confirmed, save `[LEARN:category] wrong → right` to [MEMORY.md](MEMORY.md)

Cross-session context lives in [MEMORY.md](MEMORY.md); plans, specs, and session logs are in [quality_reports/](quality_reports/). Workflow rules, skills, and agents are configured globally at `~/.Codex` (shared with the geobr / geobr-r-package projects) and apply here via path-scoping — see "Skills Quick Reference" below for what's actually live in this repo.

## Package Functions

| Function | Purpose | Notes |
| --- | --- | --- |
| `read_flights()` | Download national/international flight data (origin/destination, duration, aircraft, payload, passengers) | Data dictionary linked in roxygen `@description` |
| `read_airports()` | Download all airports/aerodromes registered with ANAC | `type = "all"/"public"/"private"` — public/private return more columns |
| `read_aircraft()` | Download the Brazilian Aeronautical Registry (RAB) | Current function — `read_aircrafts()` (plural) is hard-deprecated, use singular |
| `read_airport_movements()` | Download airport passenger/aircraft/cargo/mail movement data | Available from Jan 2019 onwards only |
| `read_airfares()` | Download domestic and international airfare data | `domestic = TRUE/FALSE` switches data source |
| `latest_flights_date()` | Check the most recent `yyyymm` date with flight data available | Support function |

All functions share `date`, `showProgress`, and `cache` roxygen `@template`s (in `man-roxygen/` or inline) — check existing templates before adding a new parameter with the same shape.

## Data Source Notes (ANAC)

- All data is sourced from ANAC's open-data portals — URLs are documented per-function in the roxygen `@description` blocks in `R/`, not duplicated here (avoid drift between two copies of the same URL).
- `read_airport_movements()` and `read_airfares()`/`read_flights()` (`date`-parameterized functions) depend on ANAC publishing cadence — "latest available month" logic lives in `utils_*.R` per data type + `latest_flights_date()`.
- Record ANAC-specific quirks (encoding, schema changes, broken URLs, rate limits) as `[LEARN:anac]` entries in [MEMORY.md](MEMORY.md) as they're discovered, rather than re-deriving them each session.
